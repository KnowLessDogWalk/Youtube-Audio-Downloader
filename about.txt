============================================================
YouTube Audio Downloader
============================================================

A personal terminal program for downloading
audio from YouTube and YouTube Music.

[Program Information]

Name    : YouTube Audio Downloader
Version : v0.3 Beta
Platform: Windows
Format  : Command Line (main.bat / fast.bat)

[Key Features]

* YouTube / YouTube Music URL audio downloading
* Original audio saving and various quality conversion options (MP3, WAV)
* Automatic audio quality and save location management (config.txt)
* Interactive settings and command support (main.bat)
* Multi-download support (batch input, comma-separated)
* Automatic failure classification and smart re-download menu
* Ultra-fast automatic download mode without confirmation (fast.bat)

[Execution Scripts]

main.bat
An interactive main script supporting quality selection,
save location changes, pre-download confirmation (Y/N),
and multi-input mode.

fast.bat
An ultra-fast automatic script that starts downloading
immediately without confirmation and automatically retries failures.

[External Dependency Files]

yt-dlp.exe
Media stream extraction and download engine

ffmpeg.exe
Audio conversion and encoding engine
